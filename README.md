# 판례 근거 답변 프로토타입

법률 고민을 적으면 관련 법령과 판례를 찾아 근거와 함께 쉬운 말로 답하는 웹 프로토타입입니다.
인프런 1:1 멘토링 실습용으로 만들었고, 멘티분이 기획하신 10단계 파이프라인을 그대로 구현했습니다.

- 데모: https://legal-precedent-prototype.vercel.app
- 법률 자문이 아닌 실험용 프로토타입입니다.

## 1. 동작 흐름

| 단계 | 하는 일 | 위치 |
|---|---|---|
| 1 입력 | 사연 입력 · 이어서 묻기(앞선 질문과 답변 최근 3번을 맥락으로 전달) | `index.html` |
| 2 질문 의도 분석 | 분야 · 알고 싶은 것 · 관련 법률 · 검색어 추출 | `api/ask.js` |
| 3 관련 법령 검색 | 법률 이름으로 현행 법령을 찾고 키워드가 들어간 조문 선택 | `findArticles` |
| 4 판례 검색 | 판례명과 본문을 함께 검색 (korean-law-mcp) | `searchPrec` |
| 4-2 에이전트 재검색 | 첫 검색 뒤 AI가 빠진 근거를 판단해 법령·판례 도구를 다시 호출 (최대 3번) | 핸들러 안 에이전트 루프 |
| 5 법률정보 RAG | 찾은 조문과 판례를 근거 자료로 묶기 (벡터 DB 없이 검색 API 기반) | 핸들러 |
| 6·8·9 추론 · 답변 · 인용 | 근거 자료 안에서만 답하고 문단마다 출처와 원문 구절 첨부 | 핸들러 |
| 7 근거 검증 | (1) 출처가 찾아 온 자료인지와 인용 구절이 원문에 글자 그대로 있는지 대조 (2) 답변에 나온 조문·사건번호를 법제처에 다시 조회 (korean-law-mcp `verify_citations`) | 핸들러 |
| 10 제공 | 답변 · 법령 · 판례 · 검증 탭과 AI가 더 찾아본 과정 표시 | `index.html` |

검증 두 가지는 서로 다른 문제를 잡습니다. 법제처 재조회는 지어낸 조문·사건번호를 잡고, 인용 대조는 실제로 있지만 질문과 상관없는 판례를 끌어오는 것을 막습니다. 다만 둘 다 해석이 맞는지까지 보장하지는 않습니다.

## 2. 로컬에서 실행

Node.js 22 이상과 Vercel CLI가 필요합니다.

```bash
npm install
cp .env.example .env.local   # 값 채우기
npx vercel dev
```

### 2.1 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | 예 | OpenAI API 키 |
| `LAW_OC` | 권장 | 법제처 Open API 인증키(OC). open.law.go.kr에서 신청. 없으면 법제처 가이드의 샘플 아이디 `test`로 동작하며 연습용으로만 쓰기 |
| `INTENT_MODEL` | 아니오 | 질문 의도 분석 모델 (기본 `gpt-6-luna`) |
| `AGENT_MODEL` | 아니오 | 재검색 에이전트 모델 (기본 `gpt-6.1-sol`) |
| `ANSWER_MODEL` | 아니오 | 답변 모델 (기본 `gpt-6.1-sol`) |

API 키는 코드에 넣지 말고 환경변수로만 넣어 주세요. Vercel에 배포할 때는 `vercel env add OPENAI_API_KEY production --sensitive`처럼 넣으면 됩니다.

## 3. 알아둘 점

- 추론 모델로 도구를 부르는 에이전트 부분은 `chat/completions`가 아니라 `/v1/responses` API를 씁니다.
- 공개 데모용으로 IP당 10분에 5회 횟수 제한이 있습니다 (인스턴스 메모리 기준이라 엄격하지 않음).
- 답변까지 보통 30초에서 1분 정도 걸립니다.
- 판례 데이터는 법제처 수록 범위(대법원 중심)에 한정됩니다.

## 4. 데이터와 오픈소스

- 법령·판례: 법제처 국가법령정보 공동활용 Open API (https://open.law.go.kr)
- 판례 검색·본문 조회·인용 재조회: [korean-law-mcp](https://github.com/chrisryugj/korean-law-mcp) v4.15.6 (MIT)
- 피드 예시 질문: 세이프홈즈·로톡에 공개된 실제 질문을 줄인 것
